CAHAYA APP V22 — MOBILE APP UI

Perubahan utama:
- Beranda mobile Pengurus/Pimpinan/Guru dibuat role-aware dan bergaya native app modern.
- Pimpinan mendapat ringkasan operasional, pengawasan, agenda, dan akses cepat tanpa pembacaan Firebase tambahan.
- Guru mendapat tombol kerja utama, jadwal saya, informasi izin kesehatan, dan akses cepat.
- Beranda Wali mendapat kartu ananda, ringkasan kehadiran/tahfiz/kedisiplinan, perkembangan terbaru, agenda & info penting, serta akses cepat.
- Mobile shell pengurus dan wali memakai header teal CAHAYA dan bottom nav premium.
- Desktop existing layout dipertahankan.
- Tidak menambah listener realtime atau download database baru; ringkasan mobile memakai data yang sudah dimuat halaman.
