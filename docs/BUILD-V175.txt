CAHAYA APP V175 — NILAI UJIAN & TINDAK LANJUT
Tanggal: 9 September 2026

1. Input Nilai Ujian
- Menambahkan kolom Keterangan pada setiap santri.
- Keterangan ikut dimuat ulang, dapat diedit sebelum FINAL, dan disimpan ke record nilai.
- Ringkasan nilai guru sekarang membawa keterangan, periode ujian, tanggal ujian, tanggal input, dan kode penilaian.

2. Tindak Lanjut Guru
- UI dirombak ke tema premium CAHAYA APP.
- Sumber utama: guru_nilai_ringkas yang dibentuk dari Nilai Ujian; fallback: nilai_ujian_bulanan.
- Hanya nilai lengkap 0–75 (inklusif) yang masuk daftar tindak lanjut.
- Data dipisahkan berdasarkan guru aktif, tahun ajaran, periode nilai, mapel dan kelas jadwal guru.
- Periode menggunakan periode_ujian, bukan tanggal input. Pada tanggal 1–7, filter default diarahkan ke bulan sebelumnya.
- Layer aksi berisi Klarifikasi Sebab, Target Perbaikan, Strategi Perbaikan, dan Status.
- Keterangan dari Nilai Ujian ditampilkan sebagai konteks pada daftar dan layer tindak lanjut.

3. Cache
- Nilai Ujian dan Tindak Lanjut dibump ke v175 pada main-dashboard.
- Root dan docs disinkronkan.
