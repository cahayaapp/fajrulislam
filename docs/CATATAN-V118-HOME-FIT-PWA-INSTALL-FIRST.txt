CAHAYA APP V118

1. Beranda Direktur mengisi viewport secara proporsional. Area Pantau Divisi fleksibel mengisi ruang sisa sehingga tidak ada area kosong besar di bawah card divisi.
2. Layar sangat pendek tetap dapat scroll agar data tidak terpotong.
3. Index memakai mode install-first: perangkat/browser yang menerima event PWA install akan melihat halaman khusus dengan tombol utama “Install Cahaya App”.
4. iOS non-standalone mendapat halaman install-first dengan petunjuk Tambahkan ke Layar Utama.
5. Jika PWA sudah berjalan standalone / browser tidak lagi menawarkan instalasi, index kembali ke alur login/sesi biasa.
6. Service worker didaftarkan dari index dan diberi fetch hook ringan untuk kompatibilitas installability browser lama.
