CAHAYA APP — PERBAIKAN 04 AGUSTUS 2026 (BATCH 2)

1. BERANDA DASHBOARD LAPTOP
- Lebar konten desktop diperluas hingga 1440 px.
- Hero dipadatkan agar tidak memakan ruang berlebihan.
- Ringkasan dibuat 4 kolom: waktu, aktivitas, hari/tanggal, dan periode akademik.
- Panel izin kesehatan dan pengawas program dibuat seimbang.
- Area jadwal dan informasi samping dirapikan agar ruang kosong berkurang.
- URL beranda diberi versi cache baru.

2. COMMAND CENTER — OBSERVASI
- Ditambahkan pilihan tampilan: Pembelajaran, Pengasuhan, Kebersihan, dan Sarpras.
- Data observasi hanya menampilkan kategori yang dipilih.
- Ditambahkan halaman input Observasi Sarpras.

3. COMMAND CENTER — JURNAL PIKET NAQIB
- Normalisasi nama blok diperbaiki agar "Blok 1" cocok dengan "blok1" pada jadwal.
- Pencocokan nama Naqib dibuat lebih toleran terhadap nama lengkap/singkatan.
- Segarkan tab sekarang melewati cache lama.
- Semua jurnal yang terekam tetap ditampilkan meskipun tidak cocok dengan slot jadwal.
- Detail jurnal dapat dibuka dari tabel Command Center.

4. COMMAND CENTER — RANKING
- Ranking tidak lagi tampil sekaligus; pengguna memilih satu jenis data.
- Pilihan: kedisiplinan guru, kedisiplinan Naqib, hafalan per santri, hafalan per surah,
  nilai ulangan tertinggi per santri, kedisiplinan per santri, dan kedisiplinan per usrah.
- Ditambahkan 10 santri terendah untuk kedisiplinan, nilai ulangan, dan hafalan.
- Nilai memadukan ulangan harian dan nilai ujian bulanan.

5. FITUR NAQIB — SKOR KEDISIPLINAN USRAH
- Halaman baru untuk melihat persentase kedisiplinan setiap usrah.
- Periode dapat dipilih: hari ini, 7 hari, atau rentang tanggal.
- Rumus: Hadir 100, Terlambat 70, Alfa 0; Izin/Sakit tidak masuk pembagi.
- Tersedia rincian skor setiap santri dalam usrah.

6. LAPOR PELANGGARAN
- Satu kejadian dapat dilaporkan untuk beberapa santri sekaligus.
- Sistem membuat satu kasus terpisah untuk setiap santri agar antrean Konselor tetap kompatibel.
- Semua laporan kelompok memiliki ID grup dan bukti foto bersama.
- Indeks laporan wali santri tetap dibuat per santri.
