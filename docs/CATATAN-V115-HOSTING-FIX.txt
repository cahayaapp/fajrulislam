CAHAYA APP v115 — GitHub Pages / Custom Domain Hotfix

1. Menambahkan CNAME root: cahayaapp.com
2. Menambahkan .nojekyll agar GitHub Pages menyajikan seluruh file statis apa adanya.
3. Menambahkan 404.html fallback yang mengarahkan kembali ke root CAHAYA APP.
4. Struktur dan tampilan v114 dipertahankan; hotfix ini fokus pada akses hosting/domain.

Jika setelah deploy masih muncul halaman GitHub Pages "There isn't a GitHub Pages site here", buka GitHub Repository > Settings > Pages dan pastikan Custom domain tetap: cahayaapp.com, lalu Save.
