CAHAYA APP V43 — Dashboard Pimpinan Grid, Ranking & Sinkronisasi Data

Fokus perubahan:
1. Dashboard Pimpinan dibuka sebagai grid menu. Detail divisi baru dimuat setelah kartu diklik.
2. Pembinaan Karakter ditegaskan sebagai Pengasuhan.
3. Persentase Pembinaan diperbaiki dengan membaca status santri dari data[] pada absensi program/pembelajaran.
4. Program Pengasuhan diselaraskan dengan master_program_harian pada Absensi, Observasi Pengasuhan, dan Dashboard Pimpinan.
5. Ditambahkan kartu Sarpras, Kesehatan, Dapur, Kebersihan, Keamanan.
6. Ditambahkan Rangking Kinerja SDM per divisi dari ketercapaian dan mutu yang tersedia.
7. Ditambahkan Rangking Usrah dari kehadiran, kedisiplinan/pelanggaran, dan nilai ujian.
8. KKM ditetapkan 75. Ulangan harian Dashboard Pimpinan mengambil nilaiUlanganHarian dari absensi_pembelajaran; ujian bulanan tetap dari nilai_ujian_bulanan.
9. Form Tahfiz: target baris disimpan sekali dan dipakai otomatis sampai diubah; riwayat setoran dapat dibuka/ditutup dan tetap dikelompokkan per bulan.
10. Cache route utama dinaikkan ke V43 untuk file yang berubah.

Catatan keamanan kompatibilitas:
- Firebase rules, login/RBAC, serta struktur data lama tidak diubah.
- Ranking dan detail data dimuat saat fitur diklik agar tidak menambah beban awal Dashboard Pimpinan.
