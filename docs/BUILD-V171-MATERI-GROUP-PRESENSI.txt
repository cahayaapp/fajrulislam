CAHAYA APP V171 - MATERI PER KELOMPOK + VALIDASI PRESENSI
Tanggal build: 9 September 2026

PERUBAHAN UTAMA
1. Target materi mengikuti kelompok pembelajaran nyata, bukan per kelas administratif.
   - Kelas yang belajar mapel sama pada sesi/jam yang sama digabung menjadi satu target.
   - Metadata kelas asal tetap disimpan untuk kompatibilitas laporan dan data lama.
2. Bahasa Arab Multazam dipisahkan menjadi target Juz 1 dan Juz 2.
   - Target Juz 1 tidak bercampur dengan Juz 2.
   - Lapor capaian materi mengikuti kelompok yang sama.
3. Presensi guru tetap wajib melalui validasi lokasi/jarak (geofence).
   - Pengecualian bebas radius lama tidak lagi melewati validasi lokasi.
4. Presensi santri dan materi:
   - Jika belum ada target materi: presensi tetap bisa disimpan.
   - Jika target materi sudah tersedia: materi wajib dipilih saat menyimpan absen akhir.
   - Al-Qur'an, Tahsin, Tahfiz, Murojaah/Murajaah: materi tidak pernah diwajibkan.
5. Target materi lama per kelas tetap dapat dibaca untuk kelompok non-Juz agar migrasi tidak memutus data sebelumnya.
6. Root dan folder docs telah disinkronkan. Cache menu dinaikkan ke v171.
