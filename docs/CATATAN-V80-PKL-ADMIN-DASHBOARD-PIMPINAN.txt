CAHAYA APP v80 — PKL ADMINISTRASI + DASHBOARD PIMPINAN RESET

PERUBAHAN UTAMA
1. Penitipan Barang tidak lagi memakai QR dan tidak tersedia di Portal Wali.
2. Buku Tamu juga dipusatkan ke role Pengurus/Tim Layanan pada Modul PKL.
3. Buku Tamu memiliki 2 submenu/tab: Isi Data dan Buku Tamu.
4. Penitipan Barang memiliki 2 submenu/tab: Isi Data dan Buku Penitipan.
5. Form penitipan mempertahankan SOP: jam layanan 13.00–17.00, pengecualian darurat, maksimal 1×/pekan di luar kunjungan bulanan, pemeriksaan isi, dan foto paket opsional.
6. Buku Penitipan menampilkan rekap wali/pengantar dan frekuensi titipan per bulan.
7. Dashboard Pimpinan dibangun ulang dari nol. Semua submenu dashboard lama dihapus.
8. Modul pertama Dashboard Pimpinan: Pantau Input Nilai.
9. Pantau Input Nilai mendukung Bulanan, Triwulan, Semester; periode dinamis; progres per guru-mapel; lengkap/parsial/belum; dan progres keseluruhan.
10. Progres lengkap dihitung berdasarkan jumlah santri pada kelas yang diampu di jadwal aktif.

PENYEMPURNAAN FINAL
- Link lama "Laporan Observasi" yang sebelumnya mengarah ke subbagian Dashboard Pimpinan dihapus agar tidak ada pintasan ke modul lama.
- Index Realtime Database nilai ujian ditambah untuk periode_ujian, jenis_ujian, tahun_akademik, guru_penguji, dan mata_pelajaran agar pemantauan lebih efisien.
