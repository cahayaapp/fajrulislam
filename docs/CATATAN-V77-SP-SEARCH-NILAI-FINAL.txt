Perbaikan:
1. Fitur Surat Peringatan (SP): nama santri kini berupa input pencarian + datalist, dan sumber nama membaca master_usrah serta data_santri termasuk format array/string.
2. Input Nilai Ujian: pencarian nama diperkuat (normalisasi huruf/diakritik + filter display langsung).
3. Input Nilai Ujian: tombol KIRIM NILAI FINAL ditambahkan. Final hanya dapat dilakukan setelah semua komponen semua santri lengkap.
4. Status final disimpan pada record nilai, indeks input, dan marker sesi nilai_input_final. Saat sesi final dibuka kembali, seluruh input dikunci.
5. Tombol Simpan Nilai Ini Dulu tetap tersedia untuk penyimpanan parsial sebelum final.

Catatan keamanan: lock FINAL ini diterapkan di data + UI. Security Rules Firebase tetap perlu diperketat agar kunci tidak dapat dibypass melalui request langsung ke database.
