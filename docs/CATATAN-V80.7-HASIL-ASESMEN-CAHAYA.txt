CAHAYA APP v80.7 — HASIL ASESMEN CAHAYA + PERIODE EFEKTIF

Perubahan:
1. Dashboard Pimpinan menambahkan menu Hasil Asesmen CAHAYA.
2. Hasil dikelompokkan per usrah dan mencakup seluruh santri pada Master Usrah, termasuk status belum ada hasil.
3. Detail laporan memakai gaya Laporan Perkembangan Karakter di Portal Wali: 5 dimensi CAHAYA + rencana tindak lanjut.
4. Pantau Asesmen CAHAYA dan Hasil Asesmen CAHAYA memakai periode efektif.
5. Jika record memiliki periode eksplisit, periode tersebut dipakai. Jika tidak, tanggal input 1–10 dianggap bulan sebelumnya; tanggal 11–akhir dianggap bulan berjalan.
6. Pada tanggal 1–10, filter default otomatis membuka bulan sebelumnya.
7. Query Dashboard Pimpinan pada main-dashboard dinaikkan ke v=80.7 untuk cache busting.
