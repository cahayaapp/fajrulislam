CAHAYA APP v119 — Index Premium & PWA Install Screen

1. Index dirombak penuh mengikuti referensi: lengkung islami, putih-teal-navy, aksen emas, dan lanskap masjid.
2. Halaman login dibuat fixed 100dvh dan tidak dapat scroll.
3. Perangkat yang belum memasang PWA mendapat layar install khusus dengan CTA utama "Install Cahaya App".
4. Layar install menampilkan manfaat Layar Penuh, Akses Cepat, dan Aman serta instruksi iOS/Android.
5. Perangkat yang sudah berjalan sebagai PWA langsung menggunakan halaman login normal.
6. Login, Firebase Auth, routing role, service worker, dan session handling dipertahankan.
