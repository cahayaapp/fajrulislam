CAHAYA APP v80.3 — PREMIUM RESPONSIVE UI/UX
Tanggal: 27 Agustus 2026

FOKUS PERUBAHAN
1. Dashboard Pimpinan
   - Redesign premium desktop + mobile.
   - Navigation rail/submenu siap dikembangkan modul demi modul.
   - Mobile: submenu menjadi bar ringkas, filter responsif, tabel progres berubah menjadi kartu data.
   - Kartu Progres Keseluruhan dibuat sebagai metrik utama.
   - Tetap khusus kepondokan; PKBM tidak dimasukkan.

2. Buku Tamu / PKL
   - Form ditegaskan untuk diisi langsung oleh tamu.
   - Tampilan form dibuat lebih ramah tamu dengan input besar dan touch target mobile.
   - Mobile Buku Tamu berubah dari tabel horizontal menjadi kartu per kunjungan.
   - Setelah simpan tidak otomatis membuka Buku Tamu; privasi data tamu lain tetap terjaga.
   - Pesan sukses meminta perangkat dikembalikan ke petugas.

3. Penitipan Barang / PKL
   - Form ditegaskan untuk diisi langsung oleh wali/pengantar/penitip.
   - SOP tetap tampil ringkas sebelum form.
   - Input dan upload foto dioptimalkan untuk mobile.
   - Mobile Buku Penitipan dan rekap wali berubah menjadi kartu data.
   - Setelah simpan tidak otomatis membuka Buku Penitipan.
   - Kontrol frekuensi, status barang, foto, dan aturan SOP tidak diubah.

4. Cache busting
   - Dashboard Pimpinan, Buku Tamu, dan Penitipan Barang diarahkan ke versi v80.3.
