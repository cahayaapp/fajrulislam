CAHAYA APP V64 — WALI PREMIUM TANPA PUSH NOTIFICATION

Basis: V63 Wali Premium.

Dipertahankan:
- Informasi Penting premium.
- Laporan Akademik, Karakter CAHAYA, dan Pembinaan premium dengan pemilih bulan.
- Riwayat Kesehatan premium.
- Perizinan premium.
- Pembatasan chat: user hanya berkomunikasi dengan Direktur, Wakil Direktur, Konselor, dan Admin.

Dinonaktifkan sementara:
- Firebase Cloud Messaging / Web Push.
- Service worker Firebase Messaging.
- Registrasi token FCM.
- Prompt izin notifikasi browser.
- Backend Cloud Functions push.

Versi ini dapat dipakai tanpa Firebase Blaze. Push Notification dapat dipasang kembali setelah Blaze siap.
