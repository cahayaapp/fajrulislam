CAHAYA APP v81 — MANAJEMEN OPERASIONAL DIVISI PENDIDIKAN
Basis: v80.7 Hasil Asesmen CAHAYA

PILIHAN PEMASANGAN
1. FULL PACKAGE
   Gunakan CAHAYA-APP-v81-Manajemen-Operasional-Pendidikan-FULL.zip untuk mengganti paket aplikasi lama secara utuh.

2. PATCH
   Gunakan CAHAYA-APP-PATCH-v81-Manajemen-Operasional-Pendidikan.zip bila instalasi aktif sudah v80.7.
   Salin seluruh isi patch ke root CAHAYA APP dan izinkan replace file dengan nama yang sama.

FITUR V81
- Absensi KBM Dua Tahap:
  Tahap 1: Hadir / Belum Hadir / Izin / Sakit.
  Tahap 2: status Belum Hadir wajib difinalisasi menjadi Terlambat / Alfa / Izin / Sakit.
  Finalisasi memperbarui record KBM yang sama.
- Guru pengganti otomatis memperoleh jadwal pengganti pada Absen Guru dan Absensi KBM setelah Manajer mencatat Guru Berhalangan.
- Kontrol Pendidikan Harian (Manajer).
- Pantau Nilai Bulanan.
- Tindak Lanjut Akademik Santri.
- Review Pendidikan Bulanan (Supervisor).
- Dashboard Direktur Pendidikan / Decision Center.
- Tindak Lanjut SDM dapat berbasis temuan kualitatif; skor tidak lagi wajib.
- Menu baru tersedia di Manajemen User dan mewarisi otorisasi lama yang setara.

CATATAN ABSENSI
Status "Belum Hadir" adalah status sementara dan bukan pelanggaran. Data disiplin seharusnya membaca status final setelah guru melakukan finalisasi akhir KBM.
