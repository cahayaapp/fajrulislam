PUSH NOTIFICATION CAHAYA
- Frontend portal Wali kini mendaftarkan perangkat untuk Web Push melalui Firebase Cloud Messaging.
- Token perangkat disimpan pada cahaya_app/fcm_tokens_wali.
- Reverse index wali-santri disimpan pada cahaya_app/fcm_wali_by_student.
- Kabar Ananda baru dapat memicu push notifikasi ke perangkat wali yang terhubung.
- Pesan baru dari Direktur/Wakil Direktur/Konselor/Admin dapat memicu push notifikasi ke perangkat wali.
- Klik notifikasi Kabar Ananda membuka Kabar Ananda.
- Klik notifikasi Pesan membuka percakapan terkait.
- Notifikasi yang diterima saat portal sedang terbuka tampil sebagai toast di dalam aplikasi.
- Service worker Firebase Messaging sudah tersedia pada wali/dashboard/firebase-messaging-sw.js.

BACKEND PUSH
